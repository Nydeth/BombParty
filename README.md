## 📌 Descripción

**BombParty** es una recreación interactiva del popular juego de agilidad mental y vocabulario. Los jugadores compiten por turnos para encontrar palabras válidas que contengan una sílaba o combinación de letras específica antes de que la bomba explote.

El objetivo principal de este proyecto es demostrar el uso de manipulación del DOM, lógica de temporizadores asíncronos y gestión del estado del juego en JavaScript.

---

## ✨ Características Principales

- ⏱️ **Temporizador dinámico:** Cuenta regresiva en tiempo real con eventos de fin de turno.
- 🔤 **Validación de palabras:** Comprobación de palabras y sílabas requeridas.
- 👥 **Soporte multijugador local / turnos:** Gestión dinámica de vidas y turnos de participantes.
- 🎨 **Interfaz de usuario intuitiva:** Diseño responsive adaptable a escritorio y dispositivos móviles.

---

## 🛠️ Tecnologías Utilizadas

- **Frontend:** HTML5, CSS3 (Flexbox/Grid, Animaciones).
- **Lógica de aplicación:** JavaScript Vanilla (ES6+).
